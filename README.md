# C-ToolKit

C-ToolKit is a menu-driven program developed in C that combines several useful mini-programs into one application. It allows users to access different tools through a simple menu system.

# Features

Pattern Generator – Creates different patterns using loops.
Pascal's Triangle – Generates Pascal's Triangle based on the number of rows.
Grade Calculator – Calculates grades based on user input.
Palindrome Checker – Determines whether a word or number is a palindrome.

# Documentation

The Documentation folder contains the following:

Algorithm – Step-by-step procedures for each program feature.
Flowchart – Visual representations of the program processes.
Pseudocode – Simplified descriptions of the program logic.
